# Rest-точка

## Назначение

**Rest-точка (Rest)** — сохранённая GPS-точка, которую приложение использует как якорь для автоматического запуска записи трека.

Когда запись трека не активна, вокруг Rest создаётся геозона радиусом **100 м**. Если пользователь покидает эту зону, приложение запускает проверку, действительно ли пользователь начал движение пешком. При подтверждении движения может быть автоматически запущена запись трека.

Rest также может автоматически переноситься, если пользователь переместился минимум на **200 м** от старого Rest, находится в состоянии покоя (трек не пишется) и с момента создания текущего Rest прошло более **30 минут**.

---



## Хранение 

Rest сохраняется в `UserDefaults`.

При сохранении Rest:

1. сохраняются координаты и timestamp;
2. создаётся или обновляется geofence;
3. обновляются debug-поля

---



# Создание Rest

Rest создаётся двумя способами.

## 1. После остановки записи

После вызова `stopTracking()` приложение пытается сохранить текущую точку как Rest.

Используется:

1. последняя точка буфера трека;
2. если её нет — текущая `locationManager.location`.

После этого:

- Rest сохраняется;
- создаётся geofence;
- запускается пассивный мониторинг.

Таким образом, после обычной прогулки Rest обычно соответствует **концу последнего трека**.

---



## 2. Первичное создание Rest

Если Rest ещё не существует, приложение может создать его автоматически после следующих событий:

- запуска приложения;
- включения Auto-start;
- получения разрешения **Always**.

---



# Пассивный мониторинг

После создания Rest приложение запускает пассивный мониторинг.

## Geofence

Если доступен `CLCircularRegion`, создаётся геозона:

- центр — Rest;
- радиус — **100 м**;
- отслеживается вход и выход из зоны.

Эта зона используется прежде всего для пробуждения приложения при выходе пользователя из Rest и последующей Auto-start verification.

---



# Перенос Rest

Перенос Rest нужен для ситуации, когда пользователь физически переместился в новое место.

Перенос происходит, если выполняются условия:

- пользователь находится минимум в **200 м** от Rest;
- состояние покоя, трек не пишется;
- с момента создания прошлой точки rest прошло более 30 минут.

Дистанция проверяется по **актуальной** GPS-позиции.

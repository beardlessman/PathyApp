# PathyApp

PathyApp — iOS-приложение для записи пеших маршрутов на карте.

## Что делает приложение

- **Записывает GPS-трек** во время прогулки: координаты, скорость, точность фиксации, направление.
- **Показывает маршрут на карте** в реальном времени и при просмотре сохранённых треков.
- **Автостарт и автоостановка**: при включённой опции трек может начаться сам, когда вы уходите от «точки отдыха», и остановиться после длительной остановки без существенного перемещения.
- **Хранит треки локально** (SwiftData) с именем, дистанцией и датой.
- **Импорт и экспорт GPX**: обмен маршрутами с другими картографическими приложениями.
- **Офлайн-карты**: тайлы подгружаются и кэшируются при просмотре и во время записи.
- **Отладочная панель** с состоянием GPS, таймером автоостановки, геозоной и логом событий.

## Платформа

- iOS, SwiftUI + MapKit
- Для фоновой записи требуется разрешение «Всегда» на геолокацию

# Сборка приложения без аккаунта разработчика Apple

Требования:
- Mac
- xcode
- iPhone

1. Открываем проект в xcode (двойной клик по PathyApp.xcodeproj в Finder)
2. Скачиваем SDK: xcode -> settings -> components. Выбираем в Add platform такую же версию iOS, какая на айфоне
3. Подключаем айфон по кабелю
4. Дожидаемся пока проиндексируются все файлы, устройства обменяются чем-то
5. В верхней части окна xcode есть панель с названием приложения (PathyApp), похожа на адресную строку в браузере. Справа от названия приложения есть настройка таргета для сборки. Выбираем там свой айфон.
6. Жмем кнопку ▶️ или сочетание клавиш Command (⌘) + R
7. Разблокируем экран устройства, подтверждаем аккаунт в настройках айфона (инструкция появится в окне xcode)
8. Закрываем приложение на айфоне или стопаем в xcode нажатием ⏹️
9. Готово! Приложение доступно на телефоне в течение недели, потом нужно повторить процедуру

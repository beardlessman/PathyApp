# Сборка приложения без аккаунта разработчика Apple

Инструкция для установки PathyApp на свой iPhone через Xcode с бесплатным Apple ID (Personal Team). Платная подписка Apple Developer не нужна.

См. также [README.md](README.md) — что делает приложение.

## Требования

- Mac с установленным **Xcode** (актуальная stable-версия из App Store)
- **iPhone** с iOS **26.4** или новее (минимальная версия проекта)
- Кабель USB / USB-C (для первой установки)
- Apple ID

## Ограничения бесплатной подписи

- Сборка на телефоне действует **около 7 дней**, затем подпись истекает
- Иконка остаётся, но приложение не запускается — нужно снова собрать из Xcode (шаги 4-5)
- Нельзя публиковать в App Store и TestFlight

## 1. Подготовка Xcode

1. Откройте проект: двойной клик по `PathyApp.xcodeproj` в Finder
2. Скачайте SDK для iOS на телефоне: **Xcode → Settings → Components → Add platform** — версия iOS как на iPhone
3. Войдите в Apple ID: **Xcode → Settings → Accounts → + → Apple ID**

## 2. Подключение iPhone

1. Подключите iPhone кабелем
2. При первом подключении на телефоне нажмите **Доверять** этому компьютеру и введите код
3. Разблокируйте экран и дождитесь, пока Xcode проиндексирует проект и «увидит» устройство

## 3. Настройка подписи в проекте

1. В Xcode откройте проект и выберите target **PathyApp**
2. Вкладка **Signing & Capabilities**:
   - **Team** → Personal Team (ваш Apple ID)
   - **Automatically manage signing** — включено
3. **Bundle Identifier** — уникальный идентификатор приложения. В репозитории сейчас `com.iambeardless.PathyApp`. Если клонируете проект себе — смените на свой (например `com.ваше-имя.PathyApp`), иначе возможен конфликт подписи

## 4. Сборка и установка

1. В верхней панели Xcode (рядом с названием **PathyApp**) выберите свой **iPhone** как устройство для запуска
2. Нажмите **▶️** или **⌘R**
3. Если Xcode просит — разблокируйте iPhone и подтвердите установку

## 5. Первый запуск на iPhone

1. **Доверие разработчику** (после первой установки):  
   **Настройки → Основные → VPN и управление устройством** → ваш профиль → **Доверять**  
   Без этого приложение не откроется, даже если Xcode показал «Build Succeeded»
2. Запустите **Pathy** и выдайте геолокацию **«Всегда»** — иначе запись трека прервётся при блокировке экрана
3. При необходимости включите **Auto-start** в настройках приложения (шестерёнка)

## Частые проблемы

| Ошибка | Что делать |
|--------|------------|
| *Signing requires a development team* | Выберите **Team** в Signing & Capabilities |
| *Failed to register bundle identifier* | Смените **Bundle Identifier** на уникальный |
| *Untrusted Developer* / приложение не открывается | **Настройки → Основные → VPN и управление устройством → Доверять** |
| iPhone не в списке устройств | Разблокируйте телефон, подтвердите «Доверять», подождите индексацию Xcode |
| *iOS XX is not installed* | Скачайте нужную platform в **Xcode → Settings → Components** |
| Трек обрывается при блокировке экрана | Выдайте геолокацию **«Всегда»**, не «При использовании» |

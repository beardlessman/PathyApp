# Changelog

## 09.06.2026

- H3 resolution повышен с 9 до 10 (~66 м ребро); при обновлении гексы переиндексируются из сохранённых треков
- Режим «Туман войны» вынесен на отдельный экран «Discovery Map»; главная карта всегда показывает линии треков
- Стилизация открытых гексов: скруглённые углы, внешняя обводка 1px без швов между соседними гексами
- Режим «Туман войны» на карте: H3 resolution 10, тайловый оверлей, индексация гексов из треков
- Кнопка Debug перенесена в настройки
- Исправлена автоостановка после короткой остановки
- Повышена плотность записи трека (~1 точка в секунду)
- Порог автостарта от точки отдыха снижен до 50 м

## 16.06.2026

- Исправлена пост-обработки после остановки: фоновая задача iOS, повтор при следующем запуске, лог пропусков, индикатор «Processing track…»
- Добавлена кнопка в UI для принудительной пост-обработки

## 14.06.2026

- Добавлена пост-обработка трека по окончании записи ([подробнее в docs/track-post-process.md]), настройки в секции «GPS filtering», обработка в фоне
- Изменён импорт GPX: несколько файлов за раз, имена по шаблону `dd MMM yyyy at HH-mm` из первой точки трека

## 10.06.2026

- Добавлена документация проекта (`docs/README.md`)
